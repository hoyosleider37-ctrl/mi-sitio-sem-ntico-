# Mi sitio semántico

Este proyecto es un sitio web creado con HTML y CSS para practicar el uso de etiquetas semánticas y estilos.

## Estructura
- index.html → Página principal
- css/styles.css → Estilos del sitio
- img/ → Carpeta para imágenes

## Instalación
1. Clonar el repositorio:  
   `git clone https://github.com/hoyosleider37-ctrl/mi-sitio-semantico.git`
2. Abrir el archivo `index.html` en el navegador.
